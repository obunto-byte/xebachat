# Security Policy

## Scope
xebachat is intended for authorized endpoint discovery and defensive assessment only.

## Reporting
Do not post sensitive findings, credentials, session identifiers, private URLs, or personal data in public issues. Share a minimal reproducible description without secrets and coordinate privately with the affected system owner.

## Safe testing
Test only against systems you own or are explicitly authorized to assess. Use conservative request rates and stop on service impact or owner request.
